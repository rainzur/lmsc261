### Arrays - storing mulitple values
let declares new array
array contents separated by commas, enclosed using brackets.
```
let fruits = ["mango", "kiwi", "strawberry", "grapes", "orange"];

let fruits = [
    "mango", 
    "kiwi"
]
```
array items are accessed using their index
``` 
let fruits = [
    "mango", 
    "kiwi", 
    "strawberry", 
    "grapes", 
    "orange"
];
print(fruits);

let fruitInstance = fruits[1];
print(fruitInstance);
```
